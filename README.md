## 🌐 Step 2: Put it on the Internet for Free ($0)

### Option A: GitHub Pages (Recommended & 100% Free Forever)
1. Go to [github.com](https://github.com) and create a free account (if you don't have one).
2. Click **New Repository**.
3. Name it: `your-username.github.io` (replace `your-username` with your exact GitHub username) or name it `portfolio`.
4. Keep it **Public**. Click **Create repository**.
5. In your terminal inside this folder (`Desktop/Own_Company`), run:
   ```bash
   git remote add origin https://github.com/<your-username>/<repo-name>.git
   git push -u origin main
   ```
6. In GitHub, go to **Settings** -> **Pages** -> under *Branch*, select `main` and `/ (root)` -> Click **Save**.
7. In 1 to 2 minutes, your website is live worldwide at: `https://<your-username>.github.io`!

---

### Option B: Netlify Drop (Drag & Drop in 60 Seconds — No Command Line)
1. Go to [app.netlify.com/drop](https://app.netlify.com/drop) and sign up for a free account.
2. Drag and drop the `Own_Company` folder onto the browser window.
3. Your site is instantly live with a free URL like `https://your-company.netlify.app`!

## 📩 Step 3: Make the Contact Form Send to Your Email ($0)

1. Go to [formspree.io](https://formspree.io) and sign up for free (50 free emails/month).
2. Click **New Form**, enter your email, and copy the Form ID (looks like `mwpkzdvo`).
3. Open `index.html`, find:
   ```html
   action="https://formspree.io/f/YOUR_FORM_ID"
   ```
4. Replace `YOUR_FORM_ID` with your real ID and save.
5. Whenever a client fills out the form, their message lands directly in your email inbox!
